# Web Server

This directory contains configuration and automation scripts for web servers:
- `0-transfer_file`: Transfers a file to a remote server via `scp` using a specified SSH private key and disabled strict host key checking.
- `1-install_nginx_web_server`: Installs Nginx and configures the default landing page.
- `2-setup_a_domain_name`: Contains the registered domain name.
- `4-not_found_page_404`: Configures a custom 404 error page.
